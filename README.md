# Someday to buy

Una lista de "algún día lo compro": apuntas lo que te tienta comprar y el botón de comprar se desbloquea solo si todavía lo quieres después de 30 días.

- Página estática de un solo archivo (`index.html`), sin servidor ni cuentas.
- Cada visitante guarda su lista en su propio navegador (`localStorage`).
- Publicada con GitHub Pages en https://somedaytobuy.com (ver `CNAME`).
